# 🎓 Траектория — чат-бот для подбора образовательных возможностей

> Цифровой навигатор по олимпиадам, конкурсам, курсам, стажировкам и другим возможностям для школьников, студентов колледжей и вузов.

**Работающее решение в MAX:** [@t411_hakaton_max_bot](https://max.ru/t411_hakaton_max_bot)

---

## 📌 Что делает бот

**«Траектория»** — чат-бот в мессенджере MAX, который помогает найти подходящие образовательные возможности по **возрасту, региону и интересам**. Работает полностью внутри MAX — не требует установки отдельных приложений.

### Ключевые функции

| Функция | Что делает |
|---|---|
| 🔍 **Подбор возможностей** | По категории (5-7, 8-9, 10-11, СПО, вуз), федеральному округу и интересам (IT, наука, инженерия, искусство, медицина, бизнес) |
| ⭐ **Избранное** | Сохранение мероприятий в личный профиль (сохраняется между перезапусками) |
| 📅 **Мои дедлайны** | Список сохранённых мероприятий, отсортированный по дате, с цветовой маркировкой срочности |
| 🔔 **Подписки** | Уведомления о новых мероприятиях по выбранным направлениям |
| ⏰ **Напоминания** | За 3 дня до дедлайна сохранённого мероприятия |
| 🧠 **GigaChat** | Свободный вопрос на естественном языке → ИИ подбирает мероприятия из базы (RAG-подход) |
| 📤 **Поделиться** | Генерация диплинка для пересылки мероприятия друзьям |
| 🔄 **Автосинхронизация** | Парсинг `olimpiada.ru` и Сириуса по расписанию (каждые 15 минут) |

## 🎯 Целевая аудитория

**Основная:** школьники 5–11 классов, студенты колледжей (СПО) и вузов (11–22 года).

**Приоритетный сегмент:** школьники 8–11 классов и студенты, активно ищущие возможности развития, но сталкивающиеся с разрозненностью информации на десятках сайтов.

**Вторичная:** родители, педагоги, наставники.

### Обоснование проблемы

- **18 млн школьников** в 38 тыс. школ РФ (2026/27 уч. год).
- **17,7 млн детей** посещают кружки и секции.
- **8,5 млн школьников** охвачены Единой моделью профориентации.
- При этом информация о возможностях **распределена по десяткам источников**, условия участия зависят от региона и возраста, а сроки подачи заявок легко пропустить.

## 🚀 Основной пользовательский сценарий

1. Пользователь открывает бота в MAX → приветствие с главным меню.
2. Нажимает **«🔍 Найти возможности»**.
3. Выбирает категорию: 5-7 / 8-9 / 10-11 класс, СПО или вуз.
4. Выбирает федеральный округ (8 округов + «Вся Россия»).
5. Выбирает интерес (IT / наука / инженерия / искусство / медицина / бизнес).
6. Получает до 5 карточек мероприятий, **отсортированных по дате дедлайна**.
7. Для каждой карточки: ⭐ В избранное, 🔗 Открыть, 📤 Поделиться, 👍/👎.
8. Управляет подписками и получает уведомления о новых мероприятиях.

## 🔒 Безопасность и работа с персональными данными

### Что хранится

Бот **не собирает персональные данные** (ФИО, телефон, email, адрес, оценки, данные о здоровье).

Единственная хранимая информация:
- **`chatId`** — внутренний идентификатор чата в MAX, необходимый для отправки сообщений.
- **Предпочтения пользователя** (избранное, подписки, реакции) — обезличенные данные, привязанные к `chatId`.

Все данные хранятся **локально** в файле `data/userdata.json` и **не передаются третьим лицам**.

### Соответствие ФЗ-152

Решение соответствует требованиям Федерального закона № 152-ФЗ «О персональных данных»:
- Персональные данные **не собираются** и не обрабатываются.
- Обезличенные данные хранятся локально и удаляются по запросу пользователя.
- Секреты (токены, ключи API) хранятся в `.env` и **не попадают в Git-репозиторий** (`data/userdata.json` и `.env` в `.gitignore`).

### Запросы к GigaChat

Функция **«🧠 Спросить GigaChat»** отправляет текст запроса пользователя на серверы GigaChat (Сбер).

⚠️ **Не рекомендуется** вводить персональные данные (ФИО, адрес, телефон, номер школы) в свободной форме.

Система **не сохраняет** историю запросов к GigaChat.

### Безопасность соединений

- Все запросы к MAX API и GigaChat — только по **HTTPS**.
- Для валидации сертификатов используется **bundle сертификатов Минцифры** (`russian_trusted_ca_bundle.pem`).
- В production-окружении (`NODE_ENV=production`) отключена возможность игнорировать ошибки TLS.

### Защита административных команд

Команды `/stats`, `/scaling`, `/roadmap`, `/partners` доступны **только администраторам**, чьи `chatId` перечислены в `.env` (`ADMIN_CHAT_IDS`). Все остальные пользователи получают ответ «⛔ Команда доступна только администраторам».

### Защита от утечки через логи

Логи не содержат тел ответов от API (там могут быть фрагменты токенов). Выводятся только HTTP-статусы и коды ошибок.

### База данных

**182 мероприятия:**
- **~120** — собраны вручную из открытых источников: сайты вузов (МГУ, МФТИ, ВШЭ, ИТМО, КФУ, УрФУ, НГУ, ДВФУ, ЮФУ и др.), «Сириус», «Движение Первых», «Большая перемена», «WorldSkills Россия».
- **~60** — добавлены автоматически через парсеры (`olimpiada.ru`, Сириус).

**Разбивка по округам:** ЦФО (15+), СЗФО (12+), ЮФО (10+), СКФО (8+), ПФО (13+), УФО (10+), СФО (10+), ДФО (8+), всероссийские/онлайн (15+).

### Формат записи

```json
{
  "id": "1",
  "title": "Олимпиада «Высшая проба»",
  "type": "олимпиада",
  "grade": ["10-11"],
  "federal_district": "ЦФО",
  "city": "Москва",

  "interests": ["IT", "математика", "наука"],

  "source": "НИУ ВШЭ",
```

### Работа с тестовыми данными

Часть записей помечена в поле `source` как «(тестовые данные)» или «(парсинг)». Это связано с тем, что:
- Ручные записи верифицированы, но не гарантируют актуальность после окончания хакатона.
- Парсинговые записи содержат неточные города и дедлайны.

В production-версии планируется периодическая верификация через официальные API.

## ⚠️ Известные ограничения

1. **Хранилище — JSON-файл.** При высокой нагрузке (1000+ пользователей одновременно) возможны задержки. В production планируется PostgreSQL.
2. **Long Polling вместо Webhook.** Используется для упрощения локальной разработки. MAX рекомендует Webhook для production.
3. **Парсинг зависит от структуры сайтов.** При изменении HTML-селекторов парсер может вернуть 0. Требуется периодическое обновление.
4. **GigaChat API имеет rate-limit.** При высокой нагрузке возможны задержки.
5. **Часть данных (парсинговые записи) может содержать неточные города и дедлайны** — помечено в поле `source` как «(парсинг)».
6. **Дедлайны условны.** Для production требуется периодическая верификация через официальные API.
7. **DNS-проблемы у некоторых провайдеров.** Для доступа к `platform-api2.max.ru` может потребоваться корректировка hosts или DNS (8.8.8.8).
